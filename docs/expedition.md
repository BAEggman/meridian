# 경락 원정

## 한 판의 흐름

오늘의 예정 과제에서 최대 여섯 문항을 골라 한 판으로 만난다. 구역 선택은 오늘 큐 안의 해당 주제를 먼저 공략하는 선택이다. 예정 복습이 신규보다 먼저이며, 예약한 첫 질문이 있으면 첫 자리를 지킨다. 갈림길에서 순서를 바꿔도 이번 판의 질문이나 총량은 사라지지 않는다.

플레이 방식에서는 검증된 원문 선택지나 유주 구절을 조작할 수 있다. 직접 회상 방식에서는 답을 보지 않고 떠올린다. 질문의 뜻을 이해하려면 선택지가 꼭 필요한 문항은 두 방식 모두 원래 보기를 사용한다.

각 응답은 판정과 결과를 확인한 뒤 다음으로 넘어간다. 한 판이 끝나면 결과 지도와 해당 질문의 원문 지식을 모아 확인한다. 잘못 답한 문항을 자동으로 추가해 판을 늘리지 않으며, 필요한 교정은 별도의 유한한 정비 원정에서 할 수 있다. 다음 원정은 명시적으로 선택한다.

## 입력 방식과 판정

| 방식 | 입력 | 판정 | 기억 지표 |
| --- | --- | --- | --- |
| 원문 선택지 대결 | 원래 보기 중 하나 선택 후 제출 | 원래 정답과 정확히 비교 | 선택형 확인 |
| 유주 순서 퍼즐 | 원래 구절 조각을 이어 붙인 순서 제출 | 원자료의 순서와 정확히 비교 | 선택형 확인 |
| 직접 회상 | 입력 또는 구술 후 원답과 정답 비교 | 자가채점 | 기존 첫 무힌트·지연 회상 조건 적용 |
| 단서·관련 도구 확인 | 도움을 본 뒤 응답 | 도움 사용을 보존 | 무힌트 성공으로 승격하지 않음 |

순서 퍼즐은 `kind: sequence`인 원문의 ` → ` 구분자에서 2~8개의 서로 다른 비어 있지 않은 조각을 얻을 수 있을 때만 만든다. 조각이 하나거나 명확하게 퍼즐화할 수 없으면 직접 회상으로 제시한다. 새로운 오답 보기, 의학적 해석, 동의어 자동 채점은 생성하지 않는다.

## 기억의 매듭과 지도

수문장은 이번 판의 예정 문항 중 과거 날짜에 실패한 실제 문제에서 고른다. 자유 회상이 불가능한 필수 선택형 문항은 일반 대결로 유지한다. 수문장이라고 원래 일일 분량 밖의 질문을 추가하지 않는다. 수문장이 예약한 첫 질문이면 입구에서 먼저 만난다.

지도는 기존 응답 이력의 명시적 증거로 계산한다.

- **회상:** 해당 카드에서 유효한 첫 무힌트 성공이 확인됨.
- **연결:** 그 성공이 서로 다른 두 날짜 이상에서 확인됨.
- **회복:** 과거 오답에 대한 날짜를 넘긴 첫 무힌트 성공이 확인됨.
- **판별:** 선택지를 보거나 원문 조각을 사용한 수행의 정답 기록.
- **교정:** 같은 날 실패하거나 답을 확인한 뒤 다시 맞힌 수행.

반복해서 정답 버튼을 누르거나 같은 답을 재전송해도 고유 카드의 성장 단계가 중복 증가하지 않는다. 이전 버전의 방문·누적 정답·숙련 숫자만으로 새로운 무힌트 성장 증거를 만들지 않는다. 게임 지도의 단계와 기존 시험 숙련 지표는 서로 다르다.

방 안에서 공개된 자료에 뒤 문항의 정답이 들어 있으면 그 뒤 문항에 노출을 기록한다. 관련 도구를 열었을 때도 같은 출처의 남은 질문을 보수적으로 처리한다. 이로써 앞서 본 답을 나중 수문장에서 다시 고른 수행이 지연 무힌트 회복으로 바뀌는 것을 막는다.

## 오늘의 분량과 종료

오늘 예정된 문항에 처음 답하는 원정과, 이미 답했지만 교정이 남은 일을 구분한다. 첫 도전이 끝났어도 기존 일정 엔진의 필수 잔량이 남아 있으면 이를 표시한다. 한 판의 끝이나 지도 성장으로 하루 목표·완전 암기를 대신하지 않는다.

당일 큐가 비면 새 모의 문제를 자동으로 이어 붙이지 않는다. 사용자는 마치거나, 남은 정비를 선택하거나, 기존 학습 도구로 이동할 수 있다. 날짜가 바뀌거나 접속하지 않았다는 이유로 벌점·기존 성장 삭제·연속 접속 손실을 주지 않는다.

## 저장과 접근성

원정은 기존 시험 상태와 중단 세션 저장을 이용한다. 별도 XP 원장이나 정답 본문 복사본을 영구히 누적하지 않는다. 실제 원답, 힌트, 선택지·조각 순서, 제출 결과와 다음 관문 대기 상태를 저장하여 새로고침이 수행을 바꾸지 않도록 한다. 기존 일반 JSON 백업, 압축 저장과 손상 기록 보호는 계속 사용한다.

효과음은 사용자가 켠 경우에만 낸다. 동작 감소 설정을 존중하며, 색뿐 아니라 선 모양·아이콘·텍스트로 결과를 구별한다. 애니메이션을 보기 위해 강제로 기다릴 필요는 없다.

모험 지도와 안내자는 학습을 위한 가상의 표현이다. 구역은 실제 일곱 학습 주제를 가리키지만, 지도의 위치·연결선은 인체나 실제 경맥 유주를 표현하지 않는다. 의학적 질문과 정답은 원자료를 사용한다.

## 설계와 검증의 범위

이 설계는 선택, 구체적인 피드백, 이야기와 실제 수행 결과를 연결하는 제품 가설이다. 개인의 몰입이나 중독을 보장하는 장치가 아니다. 게임 요소별 동기 효과가 달랐던 무작위 실험은 설계 참고 자료이며, 이 허브의 효과를 직접 검증한 연구는 아니다.

- Sailer et al. (2017), [How gamification motivates](https://doi.org/10.1016/j.chb.2016.12.033).

자동 검증은 실제 응답 판정, 유한한 원정 구성, 첫 질문 예약, 중복 성장 방지, 미래·노출 기록 구분, 기존 저장 및 원문 보존을 확인한다. 재미와 실제 공부 지속 효과는 사용 경험을 통해 확인해야 한다.
