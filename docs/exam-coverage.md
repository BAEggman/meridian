# 기말 대비 카탈로그 범위와 검증

이 파일과 `exam-catalog.js`는 `node scripts/build-exam-catalog.cjs`로 기존 `index.html`과 `saam_bosa_fill.html`에서 생성한다. 외부 지식이나 새 정답을 보태지 않는다.

## 범위

- 회상 카드 **1201장**, 주제 **7개**. 이 중 원자료 간 차이가 있는 **3장**은 `needsVerification: true`로 별도 표시한다.
- 기존 학습 도구 **22/22개**를 직접 추출하거나 동일 자료의 카드에 연결했다. 홈은 학습 도구 22개에 포함하지 않는다.
- 정적 BANK 5종 **226문항**과 경혈 생성기 **214개 원래 문항 ID**를 전량 포함한다.
- 12경맥 원문 **342구절** 모두 포함: **63개 6구절 이하 묶음**, **330개 다음 구절**.
- 교회 니모닉 **14묶음·91개 빈칸**을 모든 한자·독음·문장과 함께 포함한다.
- 사암 종합 **84맥락**, 외부 사암 補瀉 **60문항**, 원본 사암 SRS **67문항**을 포함한다.

## 분모를 읽는 법

카드 수는 **학습 단위 수**이지 독립된 지식 수·시험 문항 수·임상적 사실 수가 아니다. 원본의 서로 다른 문제 문장과 연결 회상을 보존하기 위해 기능 퀴즈·계통 트리·스와이프, 발전사·매칭·연표 사이에 같은 사실이 반복될 수 있다. 유주 원문은 구간 회상과 다음 구절 회상을 각각 연습한다. 교회 니모닉도 전체 묶음과 개별 빈칸을 별도로 센다. 사암의 직접 회상과 외부 도출식은 같은 혈 구성을 다른 문제로 연습한다. 반대로 오수혈 게임 두 종류와 자타 암송, 사암 거울/니모닉은 검증된 공통 카드에 연결하므로 게임 수만큼 전체 분모를 늘리지 않는다.

정답을 한 번 열어보거나 한 번 맞힌 것은 장기 암기를 검증한 것이 아니다. 카탈로그 포함률 100%는 원본 데이터가 시험 대비 큐에 연결되었다는 뜻이며, 사용자 암기율 100% 또는 기말 출제 범위 보증이 아니다.

## 원본 보존과 한계

- 원래 SRS 질문·정답·해설을 보존하고 HTML 태그만 일반 텍스트로 바꾼다. 고정 오답 보기는 정답이 아닌 것으로 명확히 표시하여 해설에 남긴다. `choices`는 고정 BANK의 `[a, ...d]` 원문 순서를 보존하므로 화면에서 따로 섞어야 한다. 경혈 생성 문항은 원본 빌더의 보기를 보존한다. ‘다음 중·아닌 것·옳지 않은·잘못’ 등 지시 질문 11장에는 `requiresChoices: true`를 붙인다. 해당 문항은 선택지를 기본 제공하고, 나머지에서는 선택지를 힌트로 사용할 수 있다.
- 경혈 생성기의 순방향 1개를 기본 카드로 삼고 같은 ID의 역방향 질문·답은 해설에 보존한다. 원래 무작위 보기 조합의 모든 순열은 별도 카드로 만들지 않는다.
- 사암 종합표·외부 도출식은 각각 보존한다. 학술적 교정·판본 확정은 이 빌드의 범위가 아니다. 원본 한열 표의 특이배합 주석도 보존한다. 충돌 3장의 질문·답은 원문대로 두고 `needsVerification` 및 `sourceConflict`를 추가한다. 시험 대비 엔진은 교재 확인 전 해당 항목을 확정 숙련으로 채점하지 않아야 한다.
- 배수혈맵·가리기표의 원본에는 프로토타입/교재 대조 예정 문구가 있다. 이 카탈로그는 해당 데이터를 옮겼으며 외부 표준과의 대조 검증을 완료했다고 주장하지 않는다.
- 자타의 12개 음원과 기능 암기송 6곡, 재생 속도·구절 마킹·노래 반복, 시각적 배치/시간제한은 기존 도구에 그대로 남는다. 음원 바이트·UI 설정은 암기 카드 수에 포함하지 않는다. 기능 암기송의 지식은 기능 BANK·계통 트리·스와이프 범위와 겹치며, 반복 후렴은 새 사실로 늘리지 않는다.
- 기존 로컬 진도는 출석·누적 오답·퀴즈 성적이며, 이 새 카드들의 지연 회상 성취로 자동 인정하지 않는다.

## 재생성과 검증

`node scripts/build-exam-catalog.cjs`로 재생성하고 `node scripts/build-exam-catalog.cjs --check`로 저장본과의 일치를 확인한다. 빌드 시 22도구 누락, 원래 경혈 분야 개수 불일치, 중복 ID, 빈 질문/답, 깨진 참조, 교회 니모닉과 표의 불일치, 공유한다고 선언한 사암·오수혈 데이터의 차이를 오류로 처리한다. 무작위 보기 순서는 고정 난수로 재현 가능하게 만들고 생성 날짜를 파일에 넣지 않는다. Node에서는 `require('./exam-catalog.js')`, 브라우저에서는 `window.MERIDIAN_EXAM_CATALOG`로 같은 객체를 읽는다.
